# Поведение физической панели

Согласовано 16 ноября 2026 года. Этот документ фиксирует поведение перед реализацией транспорта и прошивки.

- SW1–SW8: программируемые звуковые кнопки.
- SW9–SW12: mute каналов 1–4. Три настраиваемых цвета: канал активен, канал заглушён, канал не назначен.
- SW13–SW16: четыре пресета. При переключении текущее состояние сохраняется в предыдущий активный пресет с сохранением его имени. Ошибка записи отменяет переключение. Повторный выбор текущего слота сохраняет изменения без сброса. Пустой слот сначала заполняется через «Сохранить в пресет».
- Пока ни один пресет не выбран и не сохранён, изменения находятся в черновике. Старые настройки мигрируют без угадывания активного слота.
- Все светодиоды: WS2812B-2020. Цвета глобальные, RGB в формате #RRGGBB, выбор через палитру или ручной ввод. Прозрачность не используется. Отдельная общая яркость: 0–50%, по умолчанию 50%.
- Цвета звуковых кнопок: настроена, воспроизводится, не назначена. Цвета пресетов: активен, сохранён, пустой. Цвет периметра задаётся отдельно.
- LED1 — левый нижний угол периметра, LED2–LED8 далее по часовой стрелке. Индикаторы не относятся к ползункам.
- При потере связи только периметр мигает белым: выбран период 1 секунда, 500 мс включён / 500 мс выключен. Общий предел яркости действует и на белый. Цвета кнопок от мигания не меняются.
- При восстановлении связи приложение передаёт актуальное состояние подсветки.
- После подключения, загрузки пресета или изменения назначения канала физический ползунок не меняет громкость до пересечения текущего значения либо попадания в допуск ±0.02. Затем действует абсолютная регулировка. Mute сохраняется при движении ползунка.

В текущем этапе реализованы настройки цветов, расчёт логического кадра подсветки и автосохранение при смене пресетов. Расчёт кадра использует логические номера LED и SW, а не порядок передачи по цепочке. Подхват ползунков, обнаружение потери связи и автономное мигание на Nano реализуются в этапах протокола и прошивки. Работа и питание 24 светодиодов при 50% проверяются на оборудовании.
