# Настольное приложение DJ Poltorashka

## Требования

- Windows 10 или 11;
- Python 3.12;
- доступный системный трей.

Для передачи микрофона и звуковых кнопок в голосовой чат дополнительно нужен
[VB-CABLE с официального сайта VB-Audio](https://vb-audio.com/Cable/). Драйвер
устанавливается отдельно с правами администратора; после установки требуется
перезагрузка Windows. DJ Poltorashka не скачивает драйвер и не меняет
системные устройства Windows по умолчанию.

## Установка для разработки

Выполните команды из каталога `desktop_app`:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
```

## Запуск

Обычный запуск открывает главное окно:

```powershell
python -m dj_poltorashka
```

Фоновый запуск сразу помещает приложение в системный трей:

```powershell
python -m dj_poltorashka --background
```

Повторный обычный запуск показывает окно уже работающего приложения. Повторный
фоновый запуск проверяет существующий экземпляр и завершается без показа окна.

Закрытие главного окна скрывает его в трей. Для полного завершения выберите
`Выход` в меню трея. Если активная настройка не сохранена в пресет, приложение
предложит сохранить её, выйти без сохранения или отменить выход.

## Аудиоканалы Windows

Четырём каналам можно назначить общую громкость Windows, микрофон или отдельную
программу. Все аудиосессии выбранного `.exe` регулируются вместе. Если программа
ещё не воспроизводит звук, канал остаётся в состоянии «Ожидание программы» и
применяет выбранные громкость и mute после появления аудиосессии.

Изменения громкости и mute, сделанные средствами Windows, подхватываются
приложением и сохраняются в активный черновик. Общая громкость относится к
текущему устройству вывода Windows, включая выбранные Bluetooth-наушники.

## Звуковые кнопки

В кнопку можно импортировать MP3- или WAV-файл; приложение хранит собственную
копию в библиотеке. Нажатие кнопки в симуляторе воспроизводит её через
выбранное устройство мониторинга и одновременно отправляет в виртуальный
микрофон. Повторное нажатие той же кнопки запускает дорожку с начала без
наложения, а звуки разных кнопок могут играть одновременно.

## Виртуальный микрофон

В окне `Настройки` выберите физический микрофон и устройство мониторинга.
Вариант `Системное устройство` следует за текущим выбором Windows. Там же
доступны независимые уровни физического микрофона и звуковых кнопок. Приложение
оставляет запас громкости для одновременной речи и нескольких звуков.

В Discord или Windows Voice Recorder выберите `CABLE Output (VB-Audio Virtual
Cable)` как устройство микрофона. `CABLE Input` выбирать в голосовом чате не
нужно: это выход, в который DJ Poltorashka отправляет готовый микс.

Сервис работает всё время, пока запущено приложение:

- без VB-CABLE кнопки продолжают звучать локально, но передача в голосовой чат
  недоступна;
- без физического микрофона звуковые кнопки всё ещё передаются в `CABLE Input`;
- без устройства мониторинга виртуальный микрофон продолжает работать;
- после повторного подключения устройства маршрутизация восстанавливается
  автоматически;
- полный выход через меню трея останавливает relay, поэтому `CABLE Output`
  перестаёт получать звук.

## Данные приложения

Без явного тестового каталога приложение использует системный путь
`QStandardPaths.AppDataLocation`. Его точное расположение определяет Windows и
Qt. Документация: [QStandardPaths](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QStandardPaths.html).

В каталоге данных создаются:

- `configuration.json` — активная настройка и пресеты;
- `draft.json` — восстанавливаемая несохранённая настройка;
- `settings.json` — глобальные устройства и уровни виртуального микрофона;
- `sounds` — копии импортированных MP3/WAV;
- `logs/application.log` — журнал приложения.

Повреждённые JSON-файлы не перезаписываются автоматически. Приложение сообщает
об ошибке и использует безопасное состояние по умолчанию.

## Сборка Windows-приложения

Установите зависимости сборки и запустите скрипт из каталога `desktop_app`:

```powershell
python -m pip install -e ".[dev,build]"
powershell -ExecutionPolicy Bypass -File scripts\build_windows.ps1
```

Готовое приложение находится по пути
`dist\DJ Poltorashka\DJ Poltorashka.exe`. Фоновый запуск:

```powershell
& ".\dist\DJ Poltorashka\DJ Poltorashka.exe" --background
```

Это one-folder сборка: для переноса нужен весь каталог `DJ Poltorashka`, а не
только `.exe`. Установщик и цифровая подпись на этом этапе не создаются.

## Ограничения текущего этапа

- протокол обмена с физической панелью ещё не подключён;
- для проверки событий панели предусмотрен встроенный симулятор;
- настройка автозапуска предназначена для Windows.
